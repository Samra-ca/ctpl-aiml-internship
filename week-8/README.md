# Week 8 – CareerMind.AI

During Week 8 of my AI/ML internship, I developed **CareerMind.AI**, a full-stack AI-powered career development platform.

The project helps users improve their careers through AI-based tools for skill analysis, career planning, job recommendations, resume analysis, LinkedIn auditing, mock interviews, cover letters, salary insights, and career tracking.

The project includes features for:
- User registration and authentication
- Career profile and skills management
- AI career chat with memory
- Skill gap analysis
- Personalized career roadmaps
- AI-powered job recommendations
- Resume upload and ATS analysis
- LinkedIn profile auditing
- AI mock interviews
- Cover letter generation
- Salary insights and market trends
- Job application tracking
- Career goals and progress tracking
- Achievements and streaks
- Career analytics dashboard

The complete project is available in a separate GitHub repository:

🔗 **Project Repository:**  
https://github.com/Samra-ca/CareerMind-AI

This project helped me gain practical experience in **Artificial Intelligence, Generative AI, React, FastAPI, Python, PostgreSQL, Firebase Authentication, REST APIs, and full-stack application development**.

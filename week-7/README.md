# Week 7 – PCB Defect Detection System

During Week 7 of my AI/ML internship, I developed a **PCB Defect Detection System** for automated inspection of printed circuit boards.

The project uses a trained CNN model to detect and classify PCB defects from uploaded or captured images. It also includes Grad-CAM explainability, PCB image validation, repair-vs-scrap business logic, database storage, and analytics.

The system includes features for:
- PCB image validation
- Automated defect detection
- Classification of 6 PCB defect types
- CNN-based image classification
- Grad-CAM heatmap visualization
- Single and batch PCB inspection
- Repair vs. scrap decision logic
- PostgreSQL database integration
- Yield and defect analytics dashboard
- React-based frontend
- FastAPI backend

## Dataset Used

### Titanic Dataset

The Titanic dataset was used to perform visualization and exploratory analysis. The dataset contains passenger information such as:

* Passenger Class
* Age
* Fare
* Gender
* Survival Status
* Embarkation Details

The dataset was used to identify trends, distributions, and relationships among variables.

---

## Visualizations Created

### 1. Histogram

Used to visualize the distribution of passenger ages.

**Insights:**

* Most passengers were young adults.
* Age values were concentrated between 20 and 40 years.

---

### 2. Bar Chart

Used to visualize passenger count by travel class.

**Insights:**

* Passenger Class 3 contained the highest number of passengers.
* First and Second Class passengers were fewer in comparison.

---

### 3. Box Plot

Used to analyze Age and Fare distributions.

**Insights:**

* Fare values contain multiple outliers.
* Age distribution appears more balanced compared to Fare.

---

### 4. Correlation Heatmap

Used to identify relationships between numerical variables.

**Insights:**

* Correlation values indicate the strength of relationships between features.
* Useful for feature selection in machine learning.

---

### 5. Scatter Plot

Used to explore the relationship between Age and Fare.

**Insights:**

* Weak relationship observed between passenger age and fare.
* Some passengers paid significantly higher fares regardless of age.

---

### 6. Violin Plot

Used to compare fare distributions across passenger classes.

**Insights:**

* First Class passengers generally paid higher fares.
* Passenger Class significantly influences fare distribution.
